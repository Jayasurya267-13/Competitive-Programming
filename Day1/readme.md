problem 1
Find the Second Largest Distinct Element

You are given an array of N integers. Find the second-largest distinct element.

Input:
6
10 20 5 30 30 15

Output:
20

Explanation:
- Largest element = 30
- Second-largest distinct element = 20
Constraints:
- 2 ≤ N ≤ 100000
- -10⁹ ≤ array[i] ≤ 10⁹
Rules:
1. Don't use sorting.
2. Try to solve it in O(n) time.
3. Write your solution in Java.
4. If no second-largest distinct element exists, print -1.

problem 2
Find the Missing Number

You are given an array containing N-1 distinct numbers from 1 to N. Find the missing number.

Input:
5
1 2 4 5

Output:
3

Complexity analysis
- Time: O(n)
- Space: O(1)
